# XSSscan v1.1.5 修订版

修订版使用 `v1.1.5-r1` 标签，程序版本为 `1.1.5`。五种报告默认保留已采集的原始请求、响应和复现凭据。报告仍以私有权限写入，需要生成脱敏副本时可显式使用 `--include-raw-evidence=false`。

此版本发布已合并的 P0 和 P1 实战安全加固。四类 XSS 检测、旧 CLI 参数、置信度模型与报告 Schema 1.1 继续兼容。

- 代理凭据限定在代理认证链路。Chrome 默认使用 `--proxy`，可用 `--browser-direct` 显式直连；Chrome 证书策略由独立开关控制。
- 自动表单发现保留隐藏控件和选择项的默认值，跳过密码表单及危险动作路径。认证态的自动 POST 需要 `--allow-form-submit`。可用 `--include-url`、`--exclude-url` 和 `--no-forms` 限定扫描范围。
- 修复脱敏模式下短凭据破坏报告语义的问题。登录和令牌支持环境变量、文件或 stdin，具体入口与优先级见 [凭据说明](../credentials.md)。
- SSRF 检查使用独立策略和预编译网段。实验性 Chrome DNS 固定默认关闭，仅用于单一直接连接目标。Marker 使用加密随机源，并支持指定前缀和每轮随机前缀。
- Chrome 默认恢复站点隔离并关闭组件更新。惰性且网络安静的页面可提前结束负例观察，脚本页保留完整窗口。`--verify-full-window` 恢复原等待方式。[观察验证](../../test/verification-settle.md)
- Docker 镜像内置 Chromium，以非 root 用户运行。Go 模块路径更新为 `github.com/wqnmlgb151/XSSscan`，SDK 使用者需更新 import。[容器运行条件](../container.md)

| 校验与验收 | `SHA256SUMS`、`release-validation.json` |

压缩包包含程序、README、LICENSE、THIRD_PARTY_NOTICES 和 BUILDINFO.json。请根据 `SHA256SUMS` 校验下载文件。`release-validation.json` 记录精确源码 SHA、各平台原生验收及完整 CI。

浏览器预算默认不限，范围限于受守卫页面中可观测的请求尝试。后台 worker、浏览器自主流量和 DNS/TLS 等路径仍有计量边界。[预算说明](../../test/browser-budget-v1.1.4.md)

显式脱敏覆盖已识别的敏感位置和凭据形态。二进制未签署 Windows Authenticode 或通过 Apple 公证。完整浏览器回归在 Windows 和 Linux 上运行，五架构原生包的命令行冒烟测试使用 loopback 合成站点。[逐项验证](../security-hardening.md)
